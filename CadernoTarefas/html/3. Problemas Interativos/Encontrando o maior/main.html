Encontrando o índice do maior elemento

Imagine que você possui um vetor desconhecido de tamanho . A única forma de comparar os elementos desse vetor é por meio de uma função chamada maior3(a, b, c), que recebe três índices (cada um entre e ) e devolve o índice do maior elemento entre , e .

A sua tarefa é descobrir o índice do maior elemento do vetor .

Observe que, a cada chamada da função maior3, é possível eliminar pelo menos dois índices da lista de candidatos ao maior elemento, já que sabemos qual deles é o maior entre os três comparados.

Para ilustrar, considere um vetor desconhecido de tamanho e a seguinte sequência de chamadas à função:

1.

Se maior3(0, 1, 2) = 0, então os índices 1 e 2 não podem ser o maior elemento.

2.

Se maior3(0, 3, 4) = 3, então os índices 0 e 4 não podem ser o maior elemento.

3.

Concluímos que o índice do maior elemento é 3.

Dica: Mantenha um vetor com os possíveis índices que ainda podem corresponder ao maior elemento. A cada chamada de maior3, atualize esse conjunto, eliminando pelo menos dois índices com base no resultado obtido.
