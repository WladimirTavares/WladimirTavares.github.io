Experimento de Wason

O psicólogo Peter Wason propôs dois experimentos clássicos para investigar como as pessoas raciocinam diante de regras condicionais do tipo “se... então...”.

No primeiro experimento, apresentado de forma abstrata, menos de 10% das pessoas conseguem identificar corretamente a solução lógica. Já no segundo, formulado em um contexto mais concreto e próximo do cotidiano, a taxa de acerto costuma ultrapassar 60%.

Tente você também!

Jogo da Fatoração

Neste jogo, sua missão é descobrir um número secreto entre 1 e 100.

Para isso, você pode fazer perguntas do tipo: “O número x divide o número secreto?”

A partir das respostas, você deverá analisar possibilidades, eliminar números e usar estratégias para encontrar o segredo com o menor número possível de perguntas.

Jogo da Bolinha Mais Pesada

Uma das bolinhas é mais pesada que as demais. Seu desafio é descobrir qual delas é usando apenas uma balança de comparação.

Mas cuidado: cada pesagem é importante! Tente encontrar a bolinha mais pesada utilizando o menor número possível de pesagens.

Ao longo do jogo, você irá exercitar estratégias de divisão de casos e tomada de decisão para resolver o problema de forma eficiente.

Jogo da Celebridade

Neste jogo, seu desafio é descobrir se existe uma celebridade em uma festa.

Uma celebridade é uma pessoa que:

  • é conhecida por todos;
  • mas não conhece ninguém da festa.

Para investigar, você pode fazer perguntas do tipo: “A conhece B?”

Seu objetivo é identificar a celebridade — ou concluir que ela não existe — usando o menor número possível de perguntas.

Você possui no máximo 3(n−1) perguntas para resolver o desafio com certeza.

Ao longo do jogo, você irá exercitar estratégias de eliminação, divisão de problemas e tomada de decisão.

Cobertura com Triminós

Um tabuleiro 2ⁿ×2ⁿ possui uma única célula removida. Seu desafio é cobrir todo o restante do tabuleiro utilizando apenas peças em formato de L, chamadas triminós.

Mas existe um detalhe importante: você deve encontrar uma estratégia inteligente que resolva o problema sem usar tentativa e erro.

Ao longo do jogo, você poderá exercitar a habilidade de decompor um grande problema em problemas menores e semelhantes.

Problema da Fofoca

Imagine um grupo com N pessoas. Cada pessoa conhece inicialmente apenas um segredo diferente.

Sempre que duas pessoas conversam por telefone, elas compartilham entre si todas as fofocas que conhecem naquele momento.

Assim, ao final da ligação, as duas passam a saber exatamente os mesmos segredos.

Por exemplo, com 5 pessoas é possível fazer com que todos descubram todos os segredos usando apenas 6 ligações.

Seu desafio é descobrir estratégias eficientes para espalhar informações o mais rápido possível.

Teste sua lógica e descubra se você é um verdadeiro mestre da fofoca!

Jogo do Grafo Conexo

Um grafo secreto com 5 vértices foi gerado pelo computador. Seu desafio é descobrir se esse grafo é conexo ou não.

Para investigar a estrutura do grafo, você pode fazer perguntas do tipo: “Existe uma aresta entre os vértices vi e vj?”

A cada resposta, novas informações sobre o grafo são reveladas, e você deverá usar raciocínio lógico para decidir se é possível chegar de qualquer vértice a qualquer outro através de caminhos no grafo.

O objetivo é determinar corretamente se o grafo secreto é conexo utilizando o menor número possível de perguntas.

Jogo da Permutação

Neste jogo, o computador gera uma permutação secreta contendo de 3 a 8 números distintos.

Seu desafio é descobrir exatamente qual é essa permutação.

Para investigar a sequência secreta, você pode propor uma nova permutação ao oráculo. Como resposta, o oráculo informa quantos elementos estão na posição correta, mas não revela quais são eles.

A partir dessas pistas, você deverá usar lógica, dedução e criação de estratégias para eliminar possibilidades e identificar a permutação correta.

Experimente diferentes abordagens, teste suas estratégias e descubra quantas perguntas são necessárias para resolver o desafio.
