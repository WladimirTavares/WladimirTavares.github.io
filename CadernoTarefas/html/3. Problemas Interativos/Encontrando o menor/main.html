Encontrando o menor

Descrição do Problema:

Imagine que você possui um vetor desconhecido de tamanho . A única forma de comparar os elementos desse vetor é por meio de uma função chamada maior3(a, b, c), que recebe três índices (cada um entre e ) e devolve o índice do maior elemento entre , e .

A sua tarefa é descobrir o índice do menor elemento do vetor .

Observe que, a cada chamada da função maior3, é possível eliminar pelo menos um índice da lista de candidatos ao menor elemento, já que sabemos qual deles é o maior entre os três comparados.

Para ilustrar, considere um vetor desconhecido de tamanho e a seguinte sequência de chamadas à função:

1.

Se maior3(0, 1, 2) = 0, então o índice do menor elemento só pode ser 1 ou 2.

2.

Se maior3(1, 2, 4) = 2, então o índice do menor elemento só pode ser 1 ou 4.

3.

Se maior3(1, 4, 3) = 4, então o índice do menor elemento só pode ser 1 ou 3.

4.

Se maior3(1, 1, 3) = 1, concluímos que o índice do menor elemento é 3.

Dica: Mantenha um vetor com os possíveis índices que ainda podem corresponder ao menor elemento. A cada chamada de maior3, atualize esse conjunto, eliminando pelo menos um índice com base no resultado obtido.
