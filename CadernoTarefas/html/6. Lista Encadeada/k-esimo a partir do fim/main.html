No exemplo acima, para k = 3, o resultado esperado é:

⇒ 6

Utilize a seguinte estrutura para armazenar o resultado: 

typedef struct {
  int pos;  // posição a partir do final
  int val;  // valor do k-ésimo elemento
} resultado;

A variável pos indica a posição relativa ao final da lista, enquanto val guarda o valor do elemento correspondente. Caso o k-ésimo elemento não exista, defina val = -1.
