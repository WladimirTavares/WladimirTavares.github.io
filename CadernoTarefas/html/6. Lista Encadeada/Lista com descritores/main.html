Lista Encadeada com Descritores

Considere uma lista encadeada simples cuja estrutura inclui, além dos ponteiros para o nó cabeça e para o último nó, informações adicionais sobre o tamanho da lista e a soma dos valores armazenados. As estruturas utilizadas são as seguintes: 

typedef struct no {
    int chave;
    struct no* prox;
} no;

typedef struct lista { // Lista Encadeada Simples
    no* cabeca;
    no* ultimo;
    int tamanho;
    int soma;
} lista;
