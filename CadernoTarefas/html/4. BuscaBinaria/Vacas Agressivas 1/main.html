Vacas Agressivas

Imagine que temos uma lista ordenada contendo N números inteiros. Esses números representam as posições das baias dispostas ao longo de uma linha reta, conforme ilustrado a seguir:

Você possui C vacas (2 ≤ C ≤ N), mas elas são extremamente agressivas entre si quando colocadas em baias muito próximas — se ficarem próximas demais, acabarão se machucando.

Dada uma distância mínima D, sua tarefa é verificar se é possível distribuir as vacas nas baias de modo que a menor distância entre quaisquer duas vacas seja pelo menos D.

Se for possível realizar essa distribuição, armazene o valor 1 na variável resp; caso contrário, armazene o valor 0.

Por exemplo, considere C = 3 e D = 3. Podemos colocar as vacas nas baias de posições 1, 4 e 9. Nesse caso, a menor distância entre duas vacas será exatamente 3.
