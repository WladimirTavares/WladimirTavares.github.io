Lista Palíndrome

Imagine que p é um ponteiro para uma lista encadeada contendo números inteiros.

A tarefa consiste em:

→

verificar se a lista encadeada apontada por p é um palíndromo. Caso seja, armazene o valor 1 na variável resp; caso contrário, armazene 0.

No exemplo acima, o resultado seria:

resp => 1

Para auxiliar na implementação, utilize a seguinte estrutura: 

typedef struct {
  NoLista *cabeca;     // cabeça da sublista que será comparada
  int eh_palindrome;   // indica se a lista é palíndrome (1 ou 0)
} resultado;

Dica: Use a recursão para percorrer até o final da lista e, na volta da recursão, compare os elementos simétricos. A variável cabeca deve sempre apontar para o nó correspondente à posição inicial ainda não verificada, avançando a cada comparação. O campo eh_palindrome deve ser atualizado conforme as comparações forem sendo feitas na volta da recursão.
