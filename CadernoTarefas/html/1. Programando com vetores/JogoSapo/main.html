Jogo Pula Sapo

Imagine que você recebe uma lista de inteiros L de tamanho N representando a altura de uma sequência de canos.

Por exemplo,

Um sapo começa no primeiro cano da sequência. Para pular de um cano para o seguinte, ele precisa ter força suficiente para suportar a diferença de altura entre eles.

  • Se o próximo cano for muito alto, o sapo não consegue subir.
  • Se for muito baixo, ele não aguenta a queda.

A força necessária para um salto é dada pelo valor absoluto da diferença entre as alturas dos dois canos. Por exemplo, para ir do cano 0 (altura 1) ao cano 1 (altura 3), o sapo precisa de força igual a |3 − 1| = 2.

A sua tarefa é determinar a menor força que o sapo precisa ter para alcançar o último cano sem se machucar e armazenar esse valor na variável resp.

No exemplo acima, a força mínima necessária é 5.
