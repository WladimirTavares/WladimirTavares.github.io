Enigma do Gato Fugitivo

Abra caixas, pense com estratégia e capture o gato antes que ele escape.

🐾 Como funciona

  • Um gato está escondido em uma das caixas numeradas.
  • A cada rodada, você abre uma caixa. Se o gato estiver lá, você vence!
  • Caso contrário, durante a "noite" o gato se move para uma caixa vizinha.
  • Você não sabe onde o gato está — use lógica para encontrá-lo.
  • Existe uma estratégia que garante capturar o gato. Você consegue descobrir?

💡 Dicas progressivas
1
Observe que o gato sempre precisa se mover para uma caixa vizinha após cada rodada — ele nunca fica parado.
2
Experimente resolver primeiro o caso com apenas 2 caixas. Qual a única jogada possível?
3
Depois tente descobrir uma estratégia para 3 caixas. Pense em quais posições o gato pode estar após cada movimento.
4
Será que existe um padrão para qualquer quantidade de caixas? Tente varrer as posições de forma sistemática.
