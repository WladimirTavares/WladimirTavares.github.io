Celebridade

Considere um conjunto S de N pessoas, rotuladas de 0 até N − 1. Dizemos que uma celebridade é uma pessoa que:

  • é conhecida por todas as pessoas de S;
  • não conhece nenhuma das outras pessoas de S.

Note que pode existir no máximo uma celebridade em S. De fato, se i e j fossem ambas celebridades, então i conheceria j e j conheceria i, o que é um absurdo, pois uma celebridade não conhece ninguém.

Você tem acesso a uma função:

que devolve 1 se a pessoa i conhece j, e 0 caso contrário.

Sua tarefa é determinar se existe uma celebridade em S. Caso exista, o rótulo da pessoa deve ser armazenado na variável resp; caso contrário, resp deve receber o valor -1.

Exemplo: Considere N = 3. 

if (conhece(0,1) == 1) { // 0 não é celebridade
    if (conhece(1,2)) {  // 1 não é celebridade
        if (conhece(0,2) && !conhece(2,0) &&
            conhece(1,2) && !conhece(2,1))
            return 2;
        else
            return -1;
    } else {
        (...)
    }
} else { // 1 não é celebridade
    (...)
}

Encontre se existe uma celebridade utilizando, no máximo, 3N − 3 chamadas à função conhece.
