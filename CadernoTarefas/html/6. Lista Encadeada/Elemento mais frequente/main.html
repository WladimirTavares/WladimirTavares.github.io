Elemento mais frequente

Considere que p é um ponteiro para uma lista encadeada ordenada, na qual podem aparecer elementos repetidos.

Encontrar o elemento que aparece mais vezes na lista. Em caso de empate, deve-se escolher aquele cuja primeira ocorrência aparece mais cedo.

No exemplo, o elemento mais frequente é:

=> 8

A implementação deve ser feita de maneira recursiva.

Dica: A implementação pode ser feita da seguinte maneira: 

int elemento_frequente(NoLista * p, int maxelem, int maxfreq);

A ideia é observar que, ao percorrer a lista, sempre encontramos um bloco de elementos iguais consecutivos. Primeiro contamos quantos elementos há nesse bloco; depois comparamos essa quantidade com a maior frequência já encontrada; por fim, chamamos a função recursivamente para o restante da lista, isto é, para o nó logo após o bloco.

Dica: pense que, antes da chamada recursiva, o ponteiro p já deve ter “saltado” todo o bloco atual — isso é essencial para que cada bloco seja contado apenas uma vez.
