ORÁCULO SECRETO

🔮 cada bolinha tem um valor secreto · o oráculo revela a menor entre três

📖 COMO FUNCIONA

Cada bolinha carrega um valor secreto único que você não conhece. Você pode consultar o oráculo: apresente até 3 bolinhas (podendo repetir a mesma para "ancorar" uma comparação) e ele revela qual tem o menor valor secreto entre as apresentadas. Seu objetivo é descobrir a ordem crescente completa de todas as bolinhas usando o menor número possível de consultas.

🔮 O ORÁCULO

Apresente 2 ou 3 bolinhas (repetição permitida!). Quando só restar 2 candidatas, repita uma já conhecida como âncora: o oráculo confirmará qual das duas desconhecidas é menor.

📐 LIMITES TEÓRICOS
Selecione o tamanho para ver os limites.
💡 ESTRATÉGIA

Use inserção binária: ache o menor (1 consulta com 3 bolas), depois insira as restantes comparando com o meio da sequência já ordenada. Repetir uma bola "âncora" ao comparar com candidatas desconhecidas é chave!

⚡ Como jogar: cada bolinha possui um NÚMERO SECRETO. Consulte 3 bolinhas → o oráculo diz qual tem o menor valor secreto. Use a lógica para deduzir a ordem crescente. Arraste as bolinhas para as posições (parte inferior). Clique em "VERIFICAR ORDEM" quando pronto.
