É um heap?

Imagine uma lista L de tamanho N contendo N números inteiros. Por exemplo, suponha que L contenha 10 inteiros, indexados de 0 a 9, como ilustrado a seguir:

Esse vetor pode representa um heap máximo ou um heap mínimo.

Tarefa:

Determine se o vetor L representa um heap e armazene o resultado na variável resp, conforme as regras abaixo:

  • resp = 2, se o vetor representar um heap máximo;
  • resp = 1, se o vetor representar um heap mínimo;
  • resp = 0, caso contrário.

No exemplo acima, isso nos daria

resp => 2
