Preenchendo mais_esquerda

Imagine que o nó da árvore binária tem a seguinte estrutura: 

typedef struct NoArv{
    int valor;
    struct NoArv * esq;
    struct NoArv * dir;
    struct NoArv * mais_esquerda;
} NoArv;

Imagine que você um ponteiro p apontando para o nó raiz da árvore e que o campo mais_esquerda está igual a NULL para todos os nós da árvore apontada por p

A tarefa consiste em

→

Atualizar a árvore para que, em cada nó, o campo mais_esquerda passe a apontar para o nó mais à esquerda subárvore enraizada por cada nó.
